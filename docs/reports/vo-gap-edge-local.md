## 凡例（種別 3 分類の意味）

- **機能欠落**: 上流（基本仕様）が要求する規範が、詳細設計・インターフェースに実現形態を持たない。個別テストの穴ではなく、能力・機能レベルの欠落。広域 sweep の「抽出漏れ疑い」に対応。
- **VO 欠落**: その検査系統自体は存在するが、この特定の経路・状態・正／負の側を実際に行使する VO（検証義務）が 1 本も無い。検査の穴。広域 sweep の「未カバー」に対応。
- **局所的に弱い**: 関連 VO・詳細設計記述が意味文で触れている、または隣接ケースを行使しているが、この義務の核心を確かめていない。検査・規定の甘さ。広域 sweep の「弱い」に対応。

各行の「私の提案」は次の 3 語のいずれか 1 つです（1 行に動詞は 1 つ）。

- **追加**: 新しい機能、または新しい VO を足す。
- **統合**: 既存の名前付き VO を強化して、この義務を確かめさせる（強化先の VO 名を明記）。
- **対象外**: この義務は今回 VO 化・実装しない（理由を添える）。

## 用語の下敷き（初出時に平易化。以後、行内では用語のまま使う）

- **VO（Verification Obligation）**: 「何を検証するか」を宣言した検証義務レコード。Test はその検証実装単位。
- **chain_integrity（宣言鎖検査）／orphan_detection（孤立検出検査）／target_binding（検証対象実現検査）／oracle_presence（照合装置検査）**: v0.1 の 4 検査。
- **MISMATCH**: 宣言側（上流）を先に直すべき不一致。是正方向は「上流修正」。
- **DA-006**: 「関数本体内に assert 相当が無い」ことを FAIL 条件とする oracle_presence の判定規則。UNKNOWN 分岐を持たない。
- **assert 相当／信頼基盤**: 標準 assert 構文・フレームワークの失敗意味論・設定による列挙マクロなど、Test の成否を最終的に確定させる照合装置。
- **bare ULID / REL-\<ULID\>**: 関係（Relation）レコードの識別子。接頭辞の無い旧形式（bare ULID）を、reader は version 1 互換入力として `REL-` 付き正規形へ読み取り時に in-memory 変換する。
- **E-SCAN-010**: 関係識別子の正規化形の衝突・不一致（bare と `REL-` の重複、ファイル名と record ID のずれ）。
- **ManagedTestLink::Multiple**: 発見された 1 つの実行構成物に、対応する管理宣言（管理対象 Test Entity）が 2 件以上ある状態。対応 0 件は Missing。
- **Test Intent（intent / input / expect）**: Test が「何を検証するか・入力条件・期待」を、実装コードを読まずに判断できる形で持つ情報。
- **coverage_policy / dimensions / partition / combinations**: VO の検証空間表現。検証軸（dimensions）ごとに区分（partition）を置き、各軸独立・全直積・明示列挙（explicit）のいずれかの方針（coverage_policy）で子 VO を実体化する。明示列挙は列挙した組合せ（combinations）だけを実体化する。
- **Feature**: 基本仕様 §22.2 が集約単位として挙げる語。ただし基本仕様 §3.1 は VO と document の間に別エンティティ層を置かないと明記するため、Feature を何（VO 部分木・projection 等）として定義するかがまず要る。
- **desired state**: Create / Edit の入力として与える「あるべき最終状態」。core が結果を再スキャンして検証する。
- **判断バンドル**: 外部の判断者が判断できるよう、対象 VO・Test Intent・テストコード・対象実装・過去判断・内容ハッシュ等をまとめた派生出力。

## Owner に裁定してほしいこと

各行について、**追加**（機能または VO を足す）／**統合**（明記した既存 VO を強化してこの義務を確かめさせる）／**対象外**（VO 化・実装しない。理由添え）のいずれか 1 つを、1 行あたり 1 つ選んでください。「私の提案」欄は私の推奨であり、最終判断は Owner にあります。【ペア】と付いた行は、実現側（機能）と検証側（VO）を同時に裁定してください（片方だけ通すと、規範は入るが回帰で守れない／守る仕組みだけあって中身が無い、のいずれかになります）。この局所 sweep の裁定後は、広域 sweep（`vo-gap-candidates.md`）の同趣旨行と突き合わせ、重複 VO を生まないよう最終確認することを勧めます。
