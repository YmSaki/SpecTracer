## 2. Owner 裁定（2026-10-26、全推奨）の適用

### 問1 — 節ノードは孤児検査の対象にしない（(b)）

**内容。** `orphan_detection` は、`root` 層のノードと節ノードを除き、実効的な上流を持たない**文ノード**を孤児とする。

**理由。**
- 節ノードは規範内容を持たない容器である。節の subject hash は子ノードの hash だけを束縛する（DES-572）。
- 節に辺を足すと、配下のすべての文へ継承される（実効的な上流 = 自分の辺 ∪ 先祖の辺）。表が述べていない対応を作ってしまう。
- 利用者の文書にも必ず見出しがある。見出しにまで上流を求める検査は、構造上の理由だけで常に赤くなる。警告が無視されるようになり、本物の異常が埋もれる。

**緩めないこと。** 文ノードには、これまでどおり上流を求める。節の下にある文が上流を持たなければ、その文が孤児になる。

**変更した文。** 次の 14 文の statement を、「文ノード」「`root` 層のノードと節ノードを除き」に直した。

REQ-059 / SPEC-059 / SPEC-291 / SPEC-422 / SPEC-377 / DS-1647 / DS-1648 / DS-1649 / DS-1650 / DS-1651 / DS-1653 / DS-1654 / DS-1655 / BD-286

（SPEC-377 は文中の一部だけを直した。BD-286 は fixture の記述。）

**追加した文。** DS-1688「節ノードは規範内容を持たない容器であり、自身と先祖に上流が無くても孤児としない。配下の文ノードは、自分の辺または先祖の辺を持たなければ孤児である。」（DS-1646 の直後）
